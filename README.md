# Bar Night — มินิเกมวงเหล้า + หารบิล

เว็บแอปจริงที่รันได้ (Vite + React + Tailwind) ติดตั้งเป็น PWA บนมือถือได้ ใช้งานออฟไลน์ได้หลังโหลดครั้งแรก และเซฟบิลไว้ในเครื่องด้วย localStorage

## โครงสร้างไฟล์

```
bar-night-app/
├── index.html          จุดเริ่มต้น + ลิงก์ PWA manifest
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
├── public/
│   ├── manifest.json   ทำให้ "เพิ่มลงหน้าจอหลัก" ได้
│   ├── sw.js            service worker สำหรับใช้งานออฟไลน์
│   └── icon.svg         ไอคอนแอป
└── src/
    ├── main.jsx          entry point + ลงทะเบียน service worker
    ├── App.jsx           ทั้งแอป (เกม + หารบิล)
    └── index.css         Tailwind base
```

## ขั้นตอนรันบนเครื่องตัวเอง

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป
2. แตกไฟล์ zip แล้วเปิด terminal ในโฟลเดอร์นี้
3. ติดตั้ง dependencies:
   ```
   npm install
   ```
4. รันโหมดพัฒนา (แก้โค้ดแล้วเห็นผลทันที):
   ```
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ลิงก์ที่ terminal แสดง (ปกติ `http://localhost:5173`)
5. เมื่อพร้อมใช้งานจริง สร้างไฟล์สำหรับ production:
   ```
   npm run build
   ```
   ไฟล์ที่ได้จะอยู่ในโฟลเดอร์ `dist/`

## ขั้นตอนเอาขึ้นเว็บจริง (deploy)

ใช้ [Vercel](https://vercel.com) หรือ [Netlify](https://netlify.com) ก็ได้ ฟรีทั้งคู่:

1. อัปโหลดโค้ดนี้ขึ้น GitHub repo
2. ไปที่ Vercel/Netlify → "New Project" → เลือก repo
3. Build command: `npm run build`, Output directory: `dist`
4. กด Deploy จะได้ลิงก์ `https://your-app.vercel.app` มาใช้งานได้เลย

## ขั้นตอนติดตั้งเป็นแอปบนมือถือ (PWA)

1. เปิดลิงก์เว็บแอป (หลัง deploy แล้ว) ด้วย Chrome (Android) หรือ Safari (iPhone)
2. Android/Chrome: กดเมนู ⋮ → "เพิ่มลงหน้าจอหลัก" (Add to Home Screen)
3. iPhone/Safari: กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
4. ไอคอนแอปจะไปอยู่บนหน้าจอเหมือนแอปทั่วไป เปิดแล้วเต็มจอ ไม่มีแถบ URL
5. เนื่องจากมี service worker (`public/sw.js`) เปิดแอปซ้ำครั้งต่อไปได้แม้เน็ตไม่ดีในร้านเหล้า

> หมายเหตุ: PWA ต้องรันผ่าน HTTPS (Vercel/Netlify ให้มาอัตโนมัติ) หรือ `localhost` เท่านั้น service worker จะไม่ทำงานถ้าเปิดไฟล์ตรงๆ แบบ `file://`

## ฟีเจอร์ที่มี

- **มินิเกม 6 แบบ**: ฉันไม่เคย, ใครมีแนวโน้มจะ, Truth or Drink, บอกหมวดหมู่ (จับเวลา), นับเลขข้าม 7, ไพ่ราชา
- **หารบิลแบบแยกรายการ**: เพิ่มคนในวง เพิ่มรายการอาหาร/เครื่องดื่มพร้อมราคา เลือกได้ว่าใครกินบ้าง (ไม่บังคับหารทุกคน) ระบบคำนวณยอดแต่ละคนอัตโนมัติ รองรับ service charge / VAT
- **บันทึกบิล + ประวัติ**: กด "บันทึกบิลนี้" เพื่อเก็บสรุปไว้ดูย้อนหลังในเครื่อง (localStorage) — ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ใดๆ ข้อมูลอยู่ในมือถือ/เบราว์เซอร์ของผู้ใช้เท่านั้น
- **ใช้งานได้ต่อเนื่องแม้ปิดแอป**: บิลปัจจุบันเซฟอัตโนมัติ เปิดแอปใหม่ข้อมูลยังอยู่

## จะต่อยอดอะไรได้อีก

- เพิ่มระบบ auth + backend (เช่น Supabase/Firebase) ถ้าอยากแชร์บิลเดียวกันให้เพื่อนในวงแก้ไขพร้อมกันแบบเรียลไทม์ ตอนนี้ข้อมูลอยู่ในเครื่องใครเครื่องมันเท่านั้น
- เพิ่มปุ่ม "แชร์สรุปบิล" เป็นรูปภาพหรือลิงก์ (เช่น export เป็น PNG ด้วย html2canvas)
- เพิ่มเกมอื่นๆ ในไฟล์ `src/App.jsx` ส่วน `GAME_LIST`
